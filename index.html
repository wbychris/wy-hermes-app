WY-HERMES-ARM Agent

个人自用的自动化助手（private personal automation agent）

WY-HERMES-ARM 是部署在自有 Oracle ARM 云服务器上的个人 AI 助手实例，使用 Google Workspace API 为唯一账号持有者本人提供以下能力：

  • 读取与发送本人邮箱邮件（Gmail），用于日程提醒与待办整理；
  • 读写本人日历（Calendar），用于会议准备与时间冲突检查；
  • 读写本人云盘（Drive）、文档（Docs）与表格（Sheets），用于个人资料归档与备份；
  • 只读本人通讯录（Contacts），用于识别来信人。

本应用不面向公众开放注册，不收集、不出售、不与任何第三方共享数据。数据仅在本人的私有服务器上处理与存储。
