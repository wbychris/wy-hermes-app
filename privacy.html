隐私权政策 / Privacy Policy

应用名称：WY-HERMES-ARM Agent · 最后更新：2026-11-18

1. 适用范围

WY-HERMES-ARM Agent（下称"本应用"）是部署在应用所有者本人私有服务器上的个人自动化助手。本应用仅供账号持有者本人（下称"用户"）使用，不向公众提供注册或服务。

2. 收集与访问的信息

经用户明确授权，本应用通过 Google OAuth 2.0 访问以下用户自己的 Google 账号数据，且仅用于实现用户本人要求的自动化任务：

  • Gmail（gmail.readonly, gmail.send, gmail.modify）：读取、撰写、发送与标记用户本人的邮件；
  • Google Calendar（calendar）：读取与创建用户本人的日程事件；
  • Google Drive（drive）：读取与上传用户本人的网盘文件，用于个人资料备份；
  • Google Docs / Sheets（documents, spreadsheets）：读取与编辑用户本人的文档与表格；
  • Contacts（contacts.readonly）：只读用户本人的通讯录条目。

本应用不收集地理位置、设备标识、浏览记录、广告标识等与上述功能无关的信息。

3. 信息的使用

所访问的数据仅用于：执行用户本人发起的指令、生成用户本人需要的汇总与提醒、在用户本人的多个设备之间同步个人资料。不会用于广告投放、用户画像、模型训练或任何商业用途。

4. 信息的存储与安全

授权凭据（OAuth refresh token）与处理中间数据仅存储在用户本人控制的私有云服务器上，文件权限受限，不落地到任何第三方平台。传输过程使用 HTTPS/TLS 加密。

5. 信息的共享与披露

本应用不向任何第三方出售、出租、交易或共享用户数据。除为完成用户本人指令所必需（例如通过 Google API 写回用户自己的账号）外，不发生任何数据外传。法律强制要求时除外。

6. Google API 服务用户数据政策

本应用对从 Google API 获得的信息的使用，遵守 Google API 服务用户数据政策，包括其中的"有限使用（Limited Use）"要求。

7. 数据保留与删除

用户可随时撤销本应用的访问权限：访问 Google 账号权限页 移除本应用授权。撤销后本应用将无法再访问任何数据，本地保存的授权凭据随即失效；用户亦可要求删除服务器上由本应用产生的缓存数据。

8. 政策变更

本政策如有更新，将在本页面发布并标注更新时间。
